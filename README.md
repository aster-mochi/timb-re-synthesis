# timb-re-synthesis
Non-realtime vocal resynthesis using applied timbral descriptors

[Little comments for now we can adjust as needed later]
  - Using Text-to-speech (TTS)
  - Taking samples from user's voice
  - Making adjustments to user's voice using LPC
  - Adjustments will be made using timbral descriptors and user can adjust different levels on their own
  - Code will be done in Python, interface can be done through HTML
  - Output will be based on user input as well as adjustments made
